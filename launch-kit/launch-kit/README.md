# Kit de lancement NovaCore — mode d'emploi

Ce dossier contient **tout le contenu prêt à publier** pour promouvoir NovaCore / Nova Engine Workbench.
Il est conçu pour que **vous** publiiez, depuis vos comptes, en gardant le contrôle.

## Pourquoi ce kit existe

Une diffusion automatique du même message sur « tous les sites possibles » ne fonctionne pas :

- **Règles des plateformes** : Reddit exige une participation réelle (règle du 9:1), Hacker News n'autorise qu'un seul *Show HN* par projet, Product Hunt encadre l'auto-promotion, la plupart des Discord interdisent la pub non sollicitée.
- **Conséquence réelle** : posts supprimés, compte banni, **domaine blacklisté**. Un domaine blacklisté sur Reddit/HN est très difficile à récupérer, y compris pour les posts futurs.
- **Conversion** : un message générique envoyé partout convertit moins qu'un message adapté envoyé à une seule communauté qui comprend le sujet.

Ce kit applique donc une règle simple : **un canal, un message, un jour**, avec du contenu utile à l'audience visée.

## Règle d'or : aucun identifiant partagé

Ne transmettez jamais mot de passe, code 2FA, cookie de session ou clé API — à moi ni à aucun agent.
Un identifiant collé dans une conversation finit dans l'historique, les journaux et les sauvegardes.

## Ce qui compte le plus

1. **Répondre aux commentaires** dans les 2 heures qui suivent un post. C'est là que se jouent les premiers pilotes, pas dans le nombre de vues.
2. **Ne jamais répondre à une critique technique par du marketing.** Dire « ce n'est pas implémenté » quand ça ne l'est pas (Vulkan, Metal, ray tracing) : c'est ce qui construit une réputation.
3. **Un seul lien par post**, vers la page la plus pertinente.
