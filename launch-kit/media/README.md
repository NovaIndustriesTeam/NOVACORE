# Media

Screenshots and short captures for the press kit and channel posts.

## Needed

| File | Format | Content |
|---|---|---|
| `viewport.png` | PNG 1920×1080 | starter scene: cube, sphere, ground, grid |
| `demo.gif` | GIF/MP4, ≤ 3 MB, 15 s, silent, looped | orbit → zoom in → zoom out → entity pick |
| `render-comparison.png` | PNG, side by side | software rasterizer vs D3D12, captioned "not pixel-identical by design" |
| `feature-lab.png` | PNG 1920×1080 | 50 modules |
| `proof-terminal.png` | PNG | `83/83`, `5/5`, reference PNG hash |
| `og.png` | PNG 1200×630 | logo, title, URL readable at small size |

## Rules

- No personal data, file paths, tokens or notifications visible in any capture.
- Capture the viewport, not the whole desktop.
- The demo GIF is the highest-value asset: keep it under 3 MB or mobile readers will not wait.
- Do not caption a preview screenshot as a reference render. They are different renderers.
