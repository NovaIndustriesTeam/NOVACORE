Rendu moteur C++

Deux backends réels : rastériseur logiciel déterministe et backend GPU Direct3D 12 sous Windows. Les deux partagent les lumières multiples (directionnelle, point, spot), les textures PNG/JPEG, les shadow maps avec PCF, le HDR, le bloom et le tone mapping ACES/sRGB.

Aucun rendu pour l’instant. Le binaire doit être configuré et compilé dans Build & compilation.

Validation moteur C++

NovaEngine relit le document JSON, vérifie les identifiants, les transforms, les composants et les cycles de hiérarchie.

Sauvegarde ou compose ta scène, puis lance la validation. Le binaire doit être configuré et compilé dans Build & compilation.
État du moteur : Scene Lab, la bibliothèque de scènes, la sérialisation JSON schéma 4, la validation C++ et le moteur de rendu sont opérationnels. Le viewport navigateur utilise WebGL2 (lumières multiples, textures, HDR et bloom, mode Play) ; le rendu de référence PNG est produit par le rastériseur logiciel C++ ou par le backend Direct3D 12 sous Windows, avec shadow maps directionnelle/spot, textures PNG/JPEG et tone mapping ACES. Les ombres des lumières ponctuelles ne sont pas rendues. Il n’y a toujours pas de backend Vulkan ni Metal.
